# Data Analysis Process Checklist

## Phase 1: Ask ✅
- [ ] Define the business problem clearly
- [ ] Identify key stakeholders and their needs
- [ ] Formulate SMART questions
- [ ] Determine success metrics and KPIs
- [ ] Document assumptions and constraints
- [ ] Create project charter/scope document

## Phase 2: Prepare ✅
- [ ] Identify and access data sources
- [ ] Assess data quality and completeness
- [ ] Create data dictionary
- [ ] Document data collection methods
- [ ] Plan data cleaning strategy
- [ ] Set up data storage and organization
- [ ] Backup original data files

## Phase 3: Process ✅
- [ ] Import data into analysis tools
- [ ] Check for missing values and outliers
- [ ] Standardize data formats and types
- [ ] Remove duplicates and errors
- [ ] Validate data integrity
- [ ] Document cleaning decisions
- [ ] Create cleaned dataset versions
- [ ] Test data quality after cleaning

## Phase 4: Analyze ✅
- [ ] Perform exploratory data analysis (EDA)
- [ ] Calculate descriptive statistics
- [ ] Identify patterns and trends
- [ ] Test hypotheses
- [ ] Conduct statistical analysis
- [ ] Create correlation matrices
- [ ] Segment data appropriately
- [ ] Validate findings

## Phase 5: Share ✅
- [ ] Create compelling visualizations
- [ ] Design interactive dashboards
- [ ] Prepare presentation materials
- [ ] Write executive summary
- [ ] Document key findings
- [ ] Create data story narrative
- [ ] Prepare for stakeholder presentation

## Phase 6: Act ✅
- [ ] Provide actionable recommendations
- [ ] Prioritize recommendations by impact
- [ ] Define implementation roadmap
- [ ] Identify success metrics for recommendations
- [ ] Plan follow-up analysis
- [ ] Document lessons learned
- [ ] Create knowledge transfer materials
