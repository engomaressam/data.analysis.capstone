### 2. Portfolio Notebook Setup Steps

#### Step 1: Create New Notebook
1. Go to [Kaggle.com/code](https://www.kaggle.com/code)
2. Click **"+ Create"** → **"New Notebook"**
3. Select **"Notebook"** (not Script)
4. Change language to **"R"** (File → Language → R)

#### Step 2: Add Content Structure
```markdown
# Cyclistic Bike Share Analysis - Data Analytics Capstone Project

## Project Overview
[Business context and problem statement]

## Data Analysis Process
[Six-phase approach documentation]

## Key Findings
[Statistical insights and patterns]

## Business Recommendations
[Actionable marketing strategies]

## Technical Implementation
[Code samples and methodology]
```

#### Step 3: Add Code Cells
```r

library(tidyverse)

library(ggplot2)

# Data loading and exploration
# Statistical analysis
# Visualization creation
```

#### Step 4: Add Markdown Cells
