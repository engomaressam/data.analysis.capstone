## Question 1: Reflection
**Question**: Suppose you want to add a description of your code to your Kaggle notebook. What button will enable you to create the proper cell?

**Answer**: + Markdown

*Explanation: The + Markdown button allows you to create cells that can contain text, descriptions, and formatted content using Markdown syntax, which is perfect for adding descriptions, explanations, and documentation to your code.*

## Question 2: Portfolio Platform Reflection

The platform offers professional credibility through its established reputation, easy sharing capabilities, and integration with datasets. It allows for interactive code execution and immediate feedback from peers, making it ideal for showcasing technical skills to potential employers and collaborators.
