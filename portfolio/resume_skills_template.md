# Resume Skills Template for Data Analysts

## Technical Skills Section

### Database & Query Languages
- **SQL**: Advanced queries, data manipulation, joins, subqueries, window functions
- **Database Management**: Data extraction, transformation, and loading (ETL)
- **Data Cleaning**: Handling missing values, outliers, and data quality issues

### Programming Languages
- **R Programming**: Data analysis, statistical modeling, data visualization
- **R Packages**: tidyverse, ggplot2, dplyr, readr, lubridate
- **RStudio**: Script development, R Markdown documentation

### Data Visualization & Business Intelligence
- **Tableau**: Interactive dashboards, data storytelling, business visualizations
- **Spreadsheets**: Excel/Google Sheets - pivot tables, advanced formulas, data analysis
- **Data Storytelling**: Translating insights into compelling business narratives

### Data Analysis Tools
- **Statistical Analysis**: Descriptive statistics, hypothesis testing, correlation analysis
- **Data Cleaning**: Data validation, standardization, and integrity checks
- **Reporting**: R Markdown reports, automated documentation, change logs

- **Quality Assurance**: Validating results and ensuring data integrity
